# 官方公开样题语料

本语料用于拾句词汇学习顺序。来源为 IELTS.org 公开的阅读样题与听力录音稿；British Council 官方页面也链接到同一份 2023 阅读汇编，因此没有把镜像再计一次。

`ielts-official-public.json` 保留下载地址、手工检查过的正文页码/行边界、内容单元与年份依据。`ielts-source-lock.json` 保留每个实际下载 PDF 的 SHA-256 和首次取得时间；后续重跑会校验源文件字节。

文档中的 **2023** 来自阅读汇编文件名，**2024** 来自大字版样题末页版权标记。听力录音稿未给出文档年份。所有材料的 `examYear` 都为 `null`；这些材料不能支持“2023–2026 年真题高频”或年度变化结论。

另外检查了 Cambridge IELTS 19（官方书目发布日期 2024-06-03）和 IELTS 20（2025-07-17）。官方公开样章资产在本次获取中出现 TLS 连接关闭或 502，未取得 PDF 内容，因此没有计入词频。`recent-books-pending.json` 记录书目证据、尝试地址和未纳入的原因。出版年份也不等于实际考试年份。

正文只下载并缓存在 `.npm-cache/ielts-corpus/`，不进入源码、前端发布包或版本控制。前端使用的频次文件只有统计结果和来源元数据，不包含官方阅读原文。

## 复算

在项目根目录运行：

```powershell
node node_modules/tsx/dist/cli.mjs scripts/corpus/build.mts
node node_modules/tsx/dist/cli.mjs scripts/corpus/verify.mts
```

首次运行需联网取得 PDF 和隔离的 PDF 文本提取工具。之后可以加 `--offline` 使用相同缓存；源文件哈希变化会中止，人工检查后才能用 `--update-lock` 接受新版文件。词表及其明确列出的词形直接读取 `src/lib/corpus.ts`，新增词汇后可重跑统计。

## 统计口径

- **内容单元**：一篇不同的阅读文章或一段听力录音稿。同一篇文章在两个题型下的不同节选合成一个单元。完整阅读文章和节选都有，长度并不相等。
- **出现次数**：正文中目标词及词表显式收录词形的总次数，忽略大小写；不把 `implication` 自动合到 `imply` 等不同派生词。
- **覆盖篇数**：至少出现一次的内容单元数，同篇多次出现只计一篇。下载 PDF 数与内容单元数分别展示。
- **每万词次数**：出现次数除以全部英语词 token 数再乘 10,000。字母词 token 包含功能词，去掉数字、说话人标签、章节标签、题目指令、答案、页眉、标题、词汇表与来源说明。NFKC 统一排印连字，所有格统一到词干。
- **学习优先分**：`100 × (0.7 × 覆盖篇数 / 词表中最大覆盖篇数 + 0.3 × ln(1 + 出现次数) / ln(1 + 词表中最大出现次数))`，取整数。它是当前词表和当前样题范围内的启发式排序，增加语料或词表后会改变，不是考试出现概率或官方难度。
- **优先层级**：至少 3 篇出现为 `high`，1–2 篇为 `medium`，未观察到为 `supplementary`。未观察到不表示对雅思不重要。

`data/analysis/vocabulary-frequency.json` 是应用使用的统计；`observed-vocabulary.json` 保留所有观察到的词形/部分归并词统计；`validation.json` 记录独立正则复算和 20 词抽查。提取工具固定为 `pdfjs-dist` 4.2.67，关闭动态求值，只提取文字；不渲染 PDF。
